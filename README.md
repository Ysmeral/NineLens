## 这是什么

NineLens 是运行在《九球轮盘赌》（**Nine-Ball Roulette**）进程内部的瞄准辅助脚本。

它不属于内存修改类外挂，也不做截图识别，而是利用 **Godot 引擎自带的 `override.cfg` 自动加载机制**，
把一段 `.gd` 脚本加载进游戏进程，从而直接读取：

- 每颗球的精确坐标与编号（`Global.ball_spawn_root`）
- 6 个袋口的位置与半径（`Table/PocketArea`）
- 白色母球的位置（`Global.cue_ball`）
- 游戏自己的出杆函数（`Global.shoot(speed)`）

拿到真实数据之后，剩下的就是纯几何运算，再投影成屏幕上的线。

> 游戏本体、存档、dll 都不会被修改。卸载 = 删掉放进游戏目录的两个文件。

## 功能

| 功能 | 说明 |
|---|---|
| **瞄准线** | 从母球沿当前瞄准方向画到真实撞点，并接到被撞球的出球方向 |
| **瞄准判定** | 实时判断「现在这一杆能不能进」，给出角度容差（±x°） |
| **推荐线路** | 自动搜索所有可进球，标出目标球、袋口、幽灵球 |
| **一键出杆** | `F8` 自动挑球、自动定力度、出杆后校正方向 —— 杆头没对准也能进球 |
| **推荐开关** | `G` 一键隐藏所有推荐元素，只留自己的瞄准线 |

## 安装

1. 解压 `NineLens_V1.0.zip`
2. 完全退出游戏
3. 双击 `安装.bat`
   - 自动搜索 C~J 盘的 Steam 库
   - 找不到就把游戏根目录拖到 `安装.bat` 上
4. 启动游戏，左上角出现 `NineLens V1.0 已加载` 即生效

### 卸载

双击 `卸载.bat`，或手动删除游戏目录里的：

```
override.cfg
nbr_cheat.gd
```

## 工作原理

```
override.cfg [autoload] → 加载 nbr_cheat.gd → 与游戏同进程 → 读节点树 → 几何计算 → 投影绘制
```

1. **取数**：从 Godot 节点树里直接读球与袋口的 3D 坐标
2. **算线**：目标球与袋口连线反推幽灵球 → 射线求交得到真实撞点 → 目标球沿连心线飞出
3. **判定**：出球线与袋口中心的垂距 < 0.85 袋半径，且两条路径无遮挡
4. **绘制**：`Camera3D.unproject_position` 把 3D 点投到屏幕，在 CanvasLayer 上画线
5. **出杆**：`Global.shoot(power)`，随后读母球速度并校正方向（保留大小）

细节见 [docs/原理讲解.md](docs/原理讲解.md)。

## 从源码构建

```bash
python tools/gdcheck.py src/nbr_cheat.gd     # 括号/缩进/块头检查
python tools/gdident.py src/nbr_cheat.gd     # 未声明标识符检查
python tools/build_release.py                # 生成 dist/NineLens_V1.0.zip
```

`build_release.py` 会从 `src/nbr_cheat.gd` 里读取版本号，自动更新 `installer/说明.txt` 的版本与校验值。

## 已知限制

判定为**几何判定**，不考虑：

- 杆法（塞 / 拉 / 推）
- 库边弹性损失
- 球球之间的摩擦带偏（throw）

因此显示「可进」表示几何上可行，加塞或极薄球仍可能擦袋。
