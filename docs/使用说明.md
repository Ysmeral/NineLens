# NineLens V1.0 — Nine-Ball Roulette 瞄准辅助

进程内 GDScript 外挂。通过游戏自带的 `override.cfg` autoload 机制把脚本加载进游戏进程，
直接读取球坐标、袋口坐标、调用出杆函数 —— 数据全部来自游戏内部，不是屏幕识别。

**安装后重启游戏即生效，HUD 首行显示 `NineLens V1.0 已加载`。**

---

## 一、安装

1. 解压压缩包（必须解压，不能直接双击压缩包里的 bat）
2. 完全退出游戏（Steam 里也退干净）
3. 双击 `安装.bat`
   - 会自动在 C~J 盘找 Steam 库里的 Nine-Ball Roulette
   - 找不到就把游戏根目录拖到 `安装.bat` 上
   - 游戏装在 Program Files 里 → 右键「以管理员身份运行」
4. 启动游戏，左上角出现 `NineLens V1.0 已加载`

安装实际只做两件事：

```
游戏目录\nbr_cheat.gd      放脚本
游戏目录\override.cfg      告诉游戏加载它
```

游戏本体、存档、dll 一个字节都没改。

---

## 二、卸载

双击 `卸载.bat`，或手动删除游戏目录里这两个文件：

```
override.cfg
nbr_cheat.gd
```

删完即恢复原版，不需要「验证文件完整性」。

## 三、按键（全部只有这 9 个）

| 按键 | 功能 |
|---|---|
| `F5` | 面板开关（关掉时瞄准线一起关） |
| `F6` | 瞄准线开关（只关线，面板保留） |
| `F7` | 选中推荐目标，HUD 显示打哪颗、进哪个袋、切角多少 |
| `F8` | **出杆**：自动挑能进的球、自动定力度、出杆后校正方向 |
| `G` | 推荐线开关（关掉只剩你自己的瞄准链） |
| `T` | 换目标球（在所有可进球里循环） |
| `B` | 换袋口（同一颗球换不同袋） |
| `[` `]` | 力度 −0.5 / +0.5（默认自动） |
| `\` | 力度回到自动 |

没有别的键。误按其他功能键（Z、X、L、A、P、O、R、F9~F12）不会有任何反应。

## 四、屏幕上的东西

| 元素 | 颜色 | 含义 |
|---|---|---|
| 白球→撞点 | 黄色实线 | 白球沿当前瞄准方向走到实际撞点（两球相贴时不画） |
| 被撞球去向 | 绿色实线 | 目标球沿两球连心线飞向库边或袋口 |
| 参考线路 | 琥珀色 | 能进但可能被挡，需要打准一点 |
| 可进球的圈 | 绿色（推荐那颗）/ 白色（其它） | 有袋可进的球 |
| 撞点球 | 红色圈 | 当前瞄准会撞到的那颗球 |
| 幽灵球 | 青色小圈 | 白球球心该停的位置 |
| 袋口小点 | 绿色 5px | 判定为能进的那个袋 |

按 `G` 关掉后：参考线路、幽灵球圈、所有球的推荐圈都不画，只留你自己的瞄准链。

## 五、瞄准判定（HUD 最后一行）

实时告诉你「现在这个角度打过去，瞄着的球能不能进」。

| 显示 | 含义 |
|---|---|
| `判定 可进 5 号 → (5.63,-10.64) 容差±1.3°` | 能进，还剩 ±1.3° 余量 |
| `判定 5 号 打不进：偏 2.4°（差 0.31）` | 进不了，差多少度 / 差多少距离 |
| `判定 母球路线被挡` | 白球到撞点之间有球挡着 |
| `判定 贴死球，打不动` | 两球几乎相贴，带不动 |
| `判定 没瞄到球` | 瞄准线上没有球 |

**容差**是最有用的数字：

- `±0.3°` 左右 → 几乎必须打得极准
- `±2°` 以上 → 随手打也进

判定逻辑：目标球出球线到袋口中心的垂距 < 0.85 × 袋半径，且白球路径、目标球路径都没被挡，才算能进。

## 六、出杆（`F8`）

按一次 `F8`，自动完成：

```
1. 在所有可进线路里挑分数最高的（切角小、距离近、不挡球）
2. 按距离算力度（也可用 [ ] 固定）
3. 调游戏自己的 Global.shoot(力度)
4. 出杆瞬间读白球实际速度：方向偏差 > 10° 就改写速度方向，保留速度大小
5. 万一没生效，依次退：再次调用 → 模拟左键 → 直接给白球加速度
```

第 4 步是关键：**不受游戏自身瞄准状态影响**。杆头哪怕歪着、画面和你瞄的方向不一致，球也按算好的线路走。

力度经验值：

```
力度 ≈ 2.7 × √(总距离) + 1.2      夹在 2 ~ 14 之间
```

## 七、日志

```
D:\deepseeek\nbr_cheat\                                 ← 有就用这里
%APPDATA%\Godot\app_userdata\Nine-Ball Roulette\        ← 兜底
```

| 文件 | 内容 | 刷新 |
|---|---|---|
| `nbr_status.txt` | 母球坐标、瞄准方向、全部球坐标、命中的球、判定结果 | 每秒 |
| `aim_trace.log` | 瞄准源、角度误差、库边实测值 | 每秒 |

出现「线不对 / 没瞄到球」这类问题时，把 `nbr_status.txt` 发出来，能直接代入公式复算。

## 八、排错

| 现象 | 原因 / 处理 |
|---|---|
| 进游戏没 HUD | 没重启游戏；或 `override.cfg` 被删；查日志有没有 `NINELENS V1.0 ready` |
| 有 HUD 但没线 | 按了 `F6` 关掉了；或母球还没落位（挑战模式要先点桌面放球） |
| 按 `F8` 不出杆 | 没轮到你（HUD 里 `can=false`）；或没有可进线路（推荐行为空） |
| 线不跟鼠标转 | 该视角下杆身轴取不到，HUD 首行 `源:` 会显示兜底源 |
| 判定一直是「没瞄到球」 | 瞄准线确实指向空处；查 `nbr_status.txt` 里的 `aim_hit` 与球坐标 |
| 提示游戏正在运行 | 完全退出游戏（含 Steam 进程）再装 |

## 九、已知限制

- 只适配游戏 **1.1.5（Godot 4.6.1）**，换版本后节点名可能变，整体失效
- 判定是**几何判定**：不算杆法（塞/拉/推）、不算库边弹性、不算球球摩擦带偏（throw）
- 联机时线只画在本地，不会同步给对面
- 瞄准角依赖游戏当前状态，摆球等阶段线会停在最后一次有效值

---

## 十、原理（三段话）

1. 游戏是 Godot 引擎导出，启动会读根目录 `override.cfg`，按里面的 `[autoload]` 加载同目录的 `.gd` 脚本 —— 于是脚本和游戏同进程运行，能直接读节点树。
2. 球的位置来自 `Global.ball_spawn_root` 子节点的 `global_position`，袋口来自 `Table/PocketArea`，出杆用 `Global.shoot(speed)`（初速度 = 2 × speed，实测值）。
3. 线路是几何算出来的：目标球→袋口连线反推幽灵球 → 射线求交得到真实撞点 → 目标球沿连心线飞出 → 用相机投影画到屏幕上。
